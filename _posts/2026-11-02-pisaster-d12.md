Full details of taking RNAseq data from Day 12 for _P. ochraceus_ from DEG analysis, annotation, enrichment, and result figures. 

# Background 
From the Multi-species project, I have RNAseq data from n=6 SSWD-exposed _P. ochraceus_ and n=6 control _P. ochraceus_.  The goal is to run a differential gene expression analysis using `DESeq2` with the model of `design = ~ condition`, where the comparison will be between control and SSWD-exposed sea stars. Then, annotate the DEG list with gene ontology, and get enrichment using `topGO` with the background being all the gene ontology from all the genes from the count matrix for all _P. ochraceus_ for the multi-species project. Then, use `rrvgo` and `ggplot2` to make some result plots from the enrichment.

# Differential Gene Expression using `DESeq2` 

Differential gene expression analysis was run using the [_P. ochraceus_ gene count matrix](https://github.com/grace-ac/project-pycno-multispecies-2023/blob/main/data/pisaster_gene_count_matrix_2023_all.csv) for the libraries from Day 12 listed above (sample_ID_PSC). 

The analysis is run using `design = ~ condition` where condition is whether the sea star was SSWD-exposed or control. 

This resulted in a list of [4,376 DEGs](https://github.com/grace-ac/project-pycno-multispecies-2023/blob/main/output/44-pisaster-D12-DESeq2-topGO/DEGlist_pisaster_controlVexposed_DAY12.tab) with an adjust p-value <0.05, [2,807 of which have gene ontology annotations](https://github.com/grace-ac/project-pycno-multispecies-2023/blob/main/output/44-pisaster-D12-DESeq2-topGO/DEGlist_pisaster_controlVexposed_D12_annot.tab).

Essentially, what the code does is:     
1. make a gene universe for the background using the gene IDs from the _P. ochraceus_ gene count matrix.    
2. Create a vector for every gene for both the background and the gene list (DEGs):  

pisa.geneList       
    0     1         
27994  4376  

3. Create a GO ID map of the background (the annotated gene count matrix)     
4. Create a `topGO` object:    
```{r}
pisa.GOdata <- new(
    "topGOdata",
    ontology = "BP",
    allGenes = pisa.geneList, # degs 
    nodeSize = 5, #can comment out, but it removes spurious categories - trims out stuff with lower confidence in and core answer shuoldn't change
    geneSelectionFun = function(x) x,
    annot = annFUN.gene2GO, # for whole universe
    gene2GO = pisa.geneID2GO #for all the gene universe annotation
)
```

From [`rrvgo` vignette](https://bioconductor.org/packages/release/bioc/vignettes/rrvgo/inst/doc/rrvgo.html#plotting-and-interpretation):         
"`rrvgo` uses the similarity between pairs of terms to compute a distance matrix, defined as (1-simMatrix). The terms are then hierarchically clustered using complete linkage, and the tree is cut at the desired threshold, picking the term with the highest score as the representative of each group.
Therefore, higher thresholds lead to fewer groups, and the threshold should be read as the minimum similarity between group representatives."
