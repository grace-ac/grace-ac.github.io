I'm doing some water chemistry for oyster stuff while Jesse is out of town! 

I'll keep updating this same log and shifting the published date to the current date as I add things to it. 

Notes from Jesse:   

Mondays         
- Water quality test with API test strips each tank      
If nitrite is above 1 the water will need to be replaced in the next day or so    
If nitrite is above or  = 3 replace it as soon as possible if you have water available     

- If all other tanks are in good shape, drain and refill right blue tank with 30 ppt seatwater      
- Replace filter bag on right blue tank. I will clean them and have fresh ones ready for the next few weeks    
- Refill any grey bins with freshwater from the hose and make new seawater     
- For 30 gallons of water (the brute grey bins hold 32 but don’t fill them up all the way) Use  ~2.5 tripours full.
Make sure to check the salinity after adding two full tripours because it is easy to put a little too much     
- If you do put too much you can bail out some water with a bucket and add some more freshwater from the hose

Tuesdays        
- Water quality test with API test strips each tank 

Wednesdays      
- Water quality test with API test strips each tank 

Thursdays     
- Water quality test with API test strips each tank 
- Make sure grey bins are filled with 30 ppt water for a full drain and replacement on the left blue tank          
In the past I’ve made 33 ppt water to mix with 0ppt DI water for the yellow tanks but I still need to check with Megan if that's the plan moving forward

Fridays
- Water quality test with API test strips each tank       
If nitrite is above 1 the water will need to be replaced in the next day or so        
If nitrite is above or  = 3 replace it as soon as possible if you have water available     

- If all other tanks are in good shape, drain and refill left blue tank with 30 ppt seatwater     
- Replace filter bag on left blue tank
